# Weather Data Scraping

Monorepo for the IQ Weather Data Scraping exercise: Open-Meteo fetch, pandas processing, CSV export, matplotlib charts, FastAPI, and a React dashboard.

## Stack

- Backend: Python 3.13, FastAPI, httpx, pandas, matplotlib, pytest
- Frontend: Vite, React 19, TypeScript, Tailwind CSS, Vitest
- Runtime: Docker Compose

## Quick start

```bash
docker compose up --build
```

- Web UI: http://localhost:8080
- API docs: http://localhost:8000/docs

Local development and test commands will be documented as the project grows.
